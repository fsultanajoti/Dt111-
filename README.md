# 🎰 SaaS Casino Platform (Simulation)

A full-stack **real-time casino simulation platform** built with React, Node.js, Socket.io, and MongoDB.

> ⚠️ This project is a **virtual gaming simulation system only**. No real money is involved.

---

## 🚀 Features

### 👤 User System
- Register / Login (JWT Authentication)
- Secure session handling
- Profile management

### 💰 Virtual Wallet
- Fake coin balance system
- Deposit / Withdraw simulation
- Transaction history

### 🎮 Casino Games
- 🎰 Slot Machine
- 🎡 Roulette
- 🎲 Dice Game
- 📈 Crash Game (simulated)

### ⚡ Real-time Engine
- Socket.io live gameplay
- Multiplayer rooms
- Instant win/lose results

### 🧠 Admin Panel
- User management
- Ban / unblock users
- Game control system
- Analytics dashboard (simulated profit)

---

## 🏗️ Tech Stack

- Frontend: React 17
- Backend: Node.js + Express
- Realtime: Socket.io
- Database: MongoDB
- Auth: JWT
- Build Tool: Webpack + Babel
